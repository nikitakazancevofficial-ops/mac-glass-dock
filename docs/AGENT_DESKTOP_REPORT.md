# Genie-анимация и временная замена Dock — 21 октября 2026

> Исторический отчёт предыдущего обновления. Последующая панель слева, desktop-v6 и новые карточки описаны в [AGENT_POLISH_REPORT.md](AGENT_POLISH_REPORT.md).

## Итог текущего сеанса

В пользовательский KWin 6.8.0 загружен production-модуль `desktop-v5`, `ready:v1`, `motionShader=true`. Версия установлена отдельно: `~/.local/share/mac-glass-dock/refraction/releases/21ef6db1e384e337de06`. Загруженный ранее `.so` не перезаписывался. Новый клиент запущен из существующего проекта; подключение к compositor backend подтверждено через DBus.

После последнего разрешения пользователя включена временная замена: существующая панель Plasma **id 23** перенесена с нижнего края наверх, высота 30. Снизу работает наш Dock. Все семь виджетов сохранены: kickoff 24, pager 25, icontasks 26, marginsseparator 27, systemtray 28, digitalclock 38, showdesktop 39. Это не удаление панели и не самостоятельная реализация верхней строки macOS. Часы/лоток остаются настоящими Plasma-виджетами.

На реальном рабочем столе выполнен цикл **активация → восстановление → повторная активация**. Возврат запускался из независимой копии `~/.local/state/mac-glass-dock/recover.py`; расположение, высота, hiding и состав виджетов проверены. Итог: `active=true`, `decorated=false`.

KWin и plasmashell не перезапускались (PID 1003 и 1014 остались прежними). `kwinrc` не менялся: SHA-256 `4272f471bd9b01e7cbc5f14c1ce9353e2e2bae754547aa1e38c7d53371db3b2e`. Текущие пользовательские параметры стекла/иконок сохранены без изменения: SHA-256 INI до/после `a1d32851e4cb48d93e218d3f25d5df1ff5bd6a5007b22b5d55abbd88ac25208d`. В частности, сохранены выбранные пользователем IconSize=47 и SurfaceOpacity=0.19, а не более старые значения из снимков.

## Анимация и исправление вспышки

- Настоящая текстура окна деформируется в двухфазную Genie-воронку: формирование горловины к своей иконке, затем протягивание полотна. Восстановление разворачивает тот же путь.
- Локальное диагональное натяжение в начале, плавные quintic-профили, сетка 12–32 × 32–64, отсутствие pixel snapping вершин. Продолжительность около 620–650 мс при скорости 1; пользовательская скорость учитывается отдельно.
- Небольшой временный blur вместо сильного размазывания; почти полная непрозрачность до последних 7.5% раскрытия.
- Незавершённый переход можно развернуть. Отдельные visible/deleted refs удерживают окно лишь на необходимый срок.
- После завершения закрытия/сворачивания forced-visible ref снимается до offscreen redirect. Если другой эффект ещё удерживает окно, settled-hidden guard не позволяет нарисовать исходный прямоугольник ещё раз. Guard не удерживает текстуру или deleted ref; снимается при восстановлении/удалении.
- Repaint покрывает expandedGeometry вместе с траекторией до иконки. Это очищает деформированные участки за пределами исходного окна.
- Системные эффекты не отключались глобально. Grab role применяется к конкретному переходу. Системные, popup, lock-screen и fullscreen-окна исключены.

Описанная пользователем вспышка соответствует классу ошибок повторной отрисовки после снятия деформации. Этот путь воспроизведён принудительным удержанием тестового окна вторым visible/deleted ref на 1600 мс. Защита пресекла 24 поздние попытки отрисовки в итоговом HiDPI-прогоне. Это не утверждение, что проверены все сторонние приложения и все комбинации эффектов.

## Остальная подготовленная интеграция

- LayerShellQt Overlay, exclusiveZone=-1: размещение относительно физического края. Видимый отступ около 12 logical px, скрытая native-полоса 3 px непосредственно у края.
- KWin наблюдает указатель без перехвата ввода. Коридор показа занимает ширину Dock, включая крайние области; удерживает показ между поверхностью и нижним краем.
- Скрытие при пересечении обычным окном: реальная геометрия normal/dialog окон текущего desktop/activity, без собственного PID и минимизированных окон. SmartAutoHide оставлен в текущем пользовательском состоянии; обычное скрытие по простою доступно при выключенном smart-режиме.
- Сброс hover-оптики при полном уходе курсора, без отмены плавного возврата увеличения иконок.
- WindowTracker публикует стандартную KDE minimized geometry и реальные состояния окон. Повторный клик по активному приложению сворачивает его; следующий восстанавливает.
- Контекстное закрепление сохраняет desktop ID в XDG INI. UI-тест проверяет именно нажатие кнопки меню и сохранённое значение.
- Через 650 мс наведения появляется список настоящих окон приложения; каждая карточка активирует свой token. Есть время перехода курсора к карточкам, горизонтальная прокрутка, отсутствие захвата клавиатурного фокуса.
- Необязательные миниатюры используют KDE ScreencastingRequest/PipeWire только при реально объявленном протоколе. При отсутствии поддержки остаются название/иконка, без поддельных скриншотов. Пиксельные live-миниатюры сторонних окон в текущем сеансе отдельно не сертифицированы.
- Управление заменой и возвратом находится в панели «Стекло и Dock». Установлен пользовательский desktop entry с действиями Settings/Restore, не системный пакет.
- Подготовлена отдельная Aurorae-тема круглых кнопок с нативными close/minimize/maximize действиями и округлением верхних углов. Проверена во вложенном KWin; **в рабочем сеансе не включалась**. Пользователь может применить её отдельной кнопкой. CSD и клиентское содержимое она не переделывает.

Внешний материал самого Dock, его шейдер стекла и пользовательские оптические параметры последним обновлением не переделывались.

Визуально просмотрены промежуточные кадры **реального рендера во вложенном KWin**, например `build/tail150-genie-close-1.png`. Это собственная тестовая таблица на собственном фоне. Рабочий стол пользователя не захватывался; там проверены процессы, геометрия, DBus-состояния, отсутствие ошибок загрузки и native запуск probe. ## Возврат и следующий вход

Резервные копии Plasma/kwinrc и durable JSON находятся в `~/.local/state/mac-glass-dock`. Собственный `org.macglass.Recovery.desktop` при **следующем входе** запускает независимый `recover.py restore-login`, ждёт Plasma, возвращает прежнее расположение и отключает себя. Автозапуск нового Dock не включён. ПК не перезагружался: проверена сама программа восстановления, не полный цикл загрузки ОС.

Вернуть панель сейчас и завершить Dock:

```bash
cd /home/nikita/Projects/mac-glass-dock
./scripts/session.sh --restore-plasma
```

Если checkout перемещён, независимый откат:

```bash
python3 /home/nikita/.local/state/mac-glass-dock/recover.py restore
qdbus6 org.macglass.Dock /Dock org.macglass.Dock.quitDock
```

Запуск установленного пользовательского сценария и повторная замена:

```bash
cd /home/nikita/Projects/mac-glass-dock
./scripts/session.sh
./build/mac-glass-dock --settings
# В настройках: «Сделать основным Dock».
```

Обычный запуск сам по себе не перемещает панели. Для безопасного обычного окна остаётся `./build/mac-glass-dock --preview`.

## Ограничения и продолжение

- При первом открытии незакреплённого приложения его иконки может ещё не быть в опубликованной строке: тогда открытие использует fallback; закрытие уже получает появившуюся иконку. Это наблюдалось и на собственном неприкреплённом live probe. Закреплённые и корректно сопоставленные desktop ID имеют готовый anchor.
- Приложения с нестандартным app ID/StartupWMClass, несколько физических экранов, mixed-DPI/hotplug, HDR, длительное GPU/memory profiling требуют отдельной проверки.
- Физически точное преломление/отражение окружения, универсальная обработка клиентских углов, полная копия macOS и новая верхняя системная панель не заявляются.
- SDK-модуль привязан к KWin 6.8.0: после обновления KWin потребуется повторная проверка ABI и сборка. Новых пакетов в этом обновлении не устанавливалось, sudo не использовался.
- Следующие задачи: надёжный prelaunch-anchor для running-only приложений, длительная проверка разных типов окон и миниатюр, упаковка, CI и диагностика на нескольких GPU. Внешний вид уже понравившегося Dock сохранять.

Проверенные первичные API: [KWin OffscreenEffect](https://raw.githubusercontent.com/KDE/kwin/v6.8.0/src/effect/offscreeneffect.cpp), [visible refs / scene visibility](https://raw.githubusercontent.com/KDE/kwin/v6.8.0/src/scene/windowitem.cpp), [Plasma scripting](https://develop.kde.org/docs/plasma/scripting/api/). Геометрия Genie — собственная реализация, материалы Apple не копировались.
