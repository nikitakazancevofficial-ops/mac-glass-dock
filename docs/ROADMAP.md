# Roadmap · Дорожная карта

**First public preview: 0.4.0.** Plans are directions, not release-date promises.<br>
**Первая публичная предварительная версия: 0.4.0.** Это направления развития, без обещания сроков.

## Available / Уже есть

- Floating LayerShellQt Dock, app search/categories/pinning, live settings and icon styles.
- Compositor-assisted live background refraction and icon lenses on KWin 6.8.0.
- Spring magnification, launch bounce, Genie transitions, Reduced Motion and autohide.
- Control Center, optional window integration/previews, autostart and panel recovery.
- English/Russian guides, Arch installation helper and structured system/feedback reports.

## Next priorities / Ближайшие направления

- **Compatibility / Совместимость:** more KWin versions, GPU/driver testing, mixed-DPI monitors and hotplug, distribution reports.
- **Installation / Установка:** simpler packaging and fewer manual steps; keep a reliable basic mode when the compositor module is unavailable.
- **Experience / Удобство:** better app-ID matching, keyboard navigation, complete English UI localization and accessibility.
- **Visuals / Графика:** material/animation polish, HDR/linear-light investigation and long-session GPU/memory profiling.
- **Control Center / Центр управления:** wider hardware coverage and completion of remaining early controls.
- **File manager / Файловый менеджер:** planned future work. It is not bundled in 0.4.0; the current folder button opens the installed file manager. / Планируется отдельная работа; в 0.4.0 своего файлового менеджера ещё нет.

Help choose priorities: [report your system or leave feedback](https://github.com/nikitakazancevofficial-ops/mac-glass-dock/issues/new/choose). English and Russian welcome.
