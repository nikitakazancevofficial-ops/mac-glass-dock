# Mac Glass Dock

Плавающий Dock для KDE Plasma 6 / Wayland на C++17 и Qt Quick. Версия 0.4.0 добавляет единый объёмный стеклянный материал, адаптивные иконки, каталог приложений и компактную панель настроек.

За визуальный ориентир взят третий пользовательский референс: прозрачное тело, округлая объёмная кромка, внутреннее освещение и деликатные отражения. Ресурсы и исходники Apple не используются.

## Возможности

- Нижний Dock без рамки через LayerShellQt, с появлением от физического края экрана.
- Обратимая замена нижней панели: панель Plasma, системный лоток и часы переносятся влево. Есть кнопка возврата и отдельный автозапуск при входе в KDE.
- Системные иконки в режимах Original / Adaptive Rounded / Unified Glass. Исходные файлы иконок и desktop entries не меняются.
- Непрерывное увеличение с Gaussian falloff и пружинным сглаживанием; размеры ячеек учитывают zoom.
- Общий `VolumetricGlassSurface` для Dock, каталога, настроек, контекстного меню и подсказок.
- Системное размытие KWin в пределах скруглённой области, GPU-кромка и художественные отражения; fallback при отключении blur/GPU.
- Каталог XDG-приложений: локализованные имена, поиск, категории, прокрутка, запуск через KIO и закрепления.
- Необязательное отслеживание окон KWin: реальные индикаторы, переключение между окнами, восстановление, сворачивание и закрытие по поддерживаемым capabilities.
- Контекстное меню правой кнопкой, собственная панель настроек и выход из приложения.
- Автоскрытие, Reduced Motion, ограниченное подпрыгивание при запуске, выбор экрана и пресеты материала.
- Диагностический режим с интервалами кадров собственных окон.
- Обновление фоновых пикселей по scene damage KWin, отдельные FBO для каждого выхода в физическом разрешении.
- Единая кромка иконки и свет при наведении без дополнительной прямоугольной плашки.
- Появление, закрытие, сворачивание и восстановление окон из их иконок: двухфазная Genie-воронка, изгиб настоящей текстуры окна и краткий blur. При восстановлении полотно раскрывается обратно.
- Выбор конкретного окна через 2 секунды неподвижного наведения; одна компактная стеклянная поверхность, размытие 2.5 px и настоящее содержимое KDE/PipeWire. Без двойной рамки, повторяющихся названий и дублирующей иконки.
- Более плотный каталог приложений раскрывается Genie-воронкой из кнопки сетки и возвращается в неё. Ввод сразу принимает первый символ; хорошо видимый курсор мигает, результаты поиска появляются с короткой анимацией. Внешний клик закрывает каталог/предпросмотр через наблюдатель KWin, не забирая клик у приложения под ними.

Для Dock добавлен экспериментальный пользовательский KWin Effect: он получает уже композируемый фон под собственными surface и выполняет локальное преломление/слабое размытие по краям, включая отдельные квадратные линзы под иконками. Без загруженного эффекта используется безопасный native blur/QML fallback.

## Требования

CMake 3.21+, C++17, Qt 6.8+ (Quick, Quick Controls, ShaderTools), LayerShellQt 6, KF6 KWindowSystem / KService / KIO, SVG-плагин и тема иконок. KWayland — необязательная зависимость для управления окнами; требования её пакета к Qt могут быть выше минимальных требований Dock.

Пакеты CachyOS/Arch: `cmake gcc make qt6-base qt6-declarative qt6-shadertools qt6-svg qt6-wayland layer-shell-qt kwindowsystem kservice kio breeze-icons`; дополнительно `kwayland vulkan-headers` для локального KWin SDK-модуля. Ничего автоматически не устанавливается. Qt Test нужен только при `BUILD_TESTING=ON`.

## Сборка и запуск

```bash
./scripts/build.sh
ctest --test-dir build --output-on-failure
./build/mac-glass-dock
```

Кнопка сетки слева открывает/закрывает приложения; кнопка настроек справа — панель «Стекло и Dock». Увеличение распространяется на весь ряд, включая обе крайние кнопки и первое/последнее приложение; их увеличенная геометрия включена в область ввода. Правая кнопка по иконке открывает действия приложения. В меню есть «Выход». Escape закрывает наши панели. С модулем KWin каталог и предпросмотр закрываются по внешнему нажатию мыши/касанию; событие продолжает идти в приложение под ними. Без модуля остаются Escape, кнопка закрытия и потеря фокуса (если композитор передал фокус).

Для полёта каталога используется прозрачный travel-canvas выбранного экрана, но область ввода ограничена текущей скруглённой поверхностью и движется вместе с ней; прозрачное пространство не перехватывает мышь. Это не fullscreen-режим и не изменение геометрии самого Dock. Compositor-копия фона ограничена линзами, а не всем canvas. Размытие 2.5 px задано отдельно для предпросмотра; ваши параметры стекла Dock не переписываются.

Модуль `desktop-v8-moving-glass` деформирует и содержимое каталога, и его стеклянные линзы одной функцией Genie. Преломление и размытие живого фона продолжаются в движении, а не исчезают до конца анимации. Без этой возможности работает клиентский `.qsb` mesh-fallback (без настоящего преломления рабочего стола во время полёта); на software backend остаётся плавный scale/fade. Reduced Motion отключает полёт и появление результатов. Полная идентичность macOS не заявляется.

Обновление `desktop-v9-live-underlay` также исправляет «прилипание» деталей фона к движущемуся каталогу при масштабе преломления .94: zoom использует экранные, а не исходные координаты полотна. Неподвижное стекло Dock не изменено. [Проверка исправления](AGENT_LIVE_UNDERLAY_REPORT.md).

В `desktop-v10-panel-lifecycle` добавлена явная перерисовка сцены под движущимся каталогом и защита последнего кадра перед скрытием: прозрачный клиентский кадр и compositor guard от повторной отрисовки старой панели. Проверяется также обычный клиент без UI-тестового режима на неподвижном фоне. [Отчёт](AGENT_PANEL_LIFECYCLE_REPORT.md).

```bash
./build/mac-glass-dock --preview
./build/mac-glass-dock --launcher
./build/mac-glass-dock --settings
./build/mac-glass-dock --enable-window-tracking
./build/mac-glass-dock --diagnostics
```

Управление пользовательским модулем в текущем сеансе (из корня проекта):

```bash
./scripts/refraction.sh build
./scripts/refraction.sh install
./scripts/refraction.sh enable
./scripts/refraction.sh status
./scripts/refraction.sh disable
```

Ползунки преломления действуют сразу после загрузки модуля. «Показывать запущенные приложения» включает реальные состояния KWin; отдельный переключатель «Появление и закрытие окон» управляет compositor-анимацией. Reduced Motion отключает её. Повторный клик по активному приложению сворачивает его, следующий восстанавливает; правая кнопка позволяет выбрать окно и закрепить приложение. Для сопоставленных иконок наш эффект берёт анимацию на себя; без него координаты сворачивания передаются стандартному эффекту KDE через Plasma window management. Полная идентичность macOS не заявляется.

`--preview` оставляет обычное тестовое окно и отключает автоскрытие. `--enable-window-tracking` включает KDE-протокол для текущего запуска; из панели настроек опция сохраняется. При CLI-флаге отслеживание принудительно включено до завершения этого запуска, но сам флаг не записывается в конфигурацию. По умолчанию наблюдение/управление окнами выключено. `--diagnostics` печатает каждые 5 секунд количество кадров, средний/максимальный интервал активных кадров и DPR. Это измерение доставки кадров Qt, не GPU timestamp profiler; длительные idle-интервалы исключаются из среднего.

Скрипты собирают в один поток, чтобы снизить пиковую нагрузку на память компьютеров с 8 ГБ RAM. При достаточной свободной памяти можно увеличить параллелизм: `CMAKE_BUILD_PARALLEL_LEVEL=2 ./scripts/build.sh`. Не запускайте несколько сборок одновременно.

Release без тестового кода:

```bash
cmake -S . -B build-release -DBUILD_TESTING=OFF -DCMAKE_BUILD_TYPE=Release
cmake --build build-release --parallel 2
./build-release/mac-glass-dock
```

## Настройки

Изменения применяются сразу и сохраняются с небольшой задержкой в `$XDG_CONFIG_HOME/mac-glass-dock/settings.ini`, по умолчанию `~/.config/mac-glass-dock/settings.ini`. До первого явного изменения файл не создаётся. Ошибка сохранения отображается в настройках. Для ручной конфигурации есть [пример](../config/settings.example.ini); ручные изменения файла читаются при следующем запуске.

Основные параметры:

«Мягкое размытие стекла, px» находится в основном разделе материала. Это существующий `BlurRadius`: мягкая выборка реального фона после искажения, без размытия логотипов/текста и без нового framebuffer-прохода. Значение 0 оставляет чистое преломление; текущие пользовательские значения автоматически не меняются.

| Ключ Appearance | Диапазон / значения |
| --- | --- |
| IconSize / MaxScale / Spacing | 24–96 / 1–2 / 4–24 |
| AnimationSpeed / SpringDamping | 0.25–3 / 0.25–1 |
| SurfaceOpacity | 0.04–0.85; меньше — прозрачнее |
| Thickness | 3–24 логических px |
| EdgeReflection / HighlightIntensity | 0–1 |
| Tint | цвет `#RRGGBB` |
| IconStyle | original / adaptive / glass |
| Theme | auto / light / dark |
| GpuEffects / BlurEnabled | true / false |
| AutoHide / ReducedMotion / BounceEnabled | true / false |
| WindowIntegration | false по умолчанию |
| WindowAnimations | true; применяется при включённой интеграции и доступном KWin-модуле |
| ScreenName | имя из панели настроек; пусто — основной экран |

Пресеты: «Со скринов» — рекомендуемые параметры пользователя; Crystal Clear — прозрачный материал; Deep Glass — более плотный и глубокий; Soft Glass — облегчённая QML-оптика. Расширенные параметры преломления доступны после загрузки KWin Effect. Автотема следует теме системы, не анализирует обои.

`Applications/Pinned` содержит desktop ID через запятую, максимум 24. Запуск передаётся KIO, пользовательские строки не превращаются в shell-команды. Индикатор ожидания запуска не подменяет индикатор открытого окна.

Автоскрытие оставляет полосу 3 логических px по ширине Dock у физического нижнего края (`exclusiveZone=-1`). При работающем KWin-модуле указатель наблюдается композитором: вся область между Dock и нижним краем вызывает показ без перехвата ввода. «Скрывать при перекрытии окном» включает интеллектуальный режим; без него Dock скрывается через 900 мс простоя. Карточки окон и открытые настройки приостанавливают скрытие.

В настройках справа в Dock есть «Сделать основным Dock», «Вернуть панель Plasma», переключатель автозапуска и отдельный возврат оформления окон. Замена перемещает существующую нижнюю панель влево, сохраняя все её виджеты. Без включённого автозапуска режим временный: следующий вход возвращает исходную панель. При включённом автозапуске Dock и установленный модуль стекла запускаются после готовности KDE; выбранная левая панель и пользовательские настройки сохраняются. Старое задание восстановления отключается, чтобы не конкурировать с запуском Dock.

```bash
python3 scripts/desktop-session.py enable-autostart
python3 scripts/desktop-session.py status
# Отключить следующий автоматический запуск, не закрывая текущий Dock:
python3 scripts/desktop-session.py disable-autostart
# Сразу вернуть исходную панель и отключить автозапуск Dock:
./scripts/session.sh --restore-plasma
```

Используются пользовательская запись `~/.config/autostart/org.macglass.Dock.desktop`, скрипт KDE `~/.config/autostart-scripts/org.macglass.Dock` и служба `mac-glass-dock-login.service` в systemd --user; помощник защищён от дублирования. Программа запуска/восстановления хранится отдельно от checkout в `$XDG_STATE_HOME/mac-glass-dock/recover.py`, журнал — `login.log`, исходные резервные копии — `original/`. Она не запускает второй готовый Dock. Если проект или сборка исчезли либо Dock не стартовал, программа пытается восстановить исходную панель и отключает собственный автозапуск. Не перемещайте проект и не удаляйте `build/mac-glass-dock`, пока автозапуск включён; после переноса повторно включите его из нового каталога. Это не системная служба и не изменение настроек эффектов KWin.

Оформление «Mac Glass — Soft Corners» использует Aurorae, мягкие верхние углы и рабочие круглые кнопки закрытия, сворачивания и разворачивания. Оно меняет серверные рамки KWin, а не внутренний интерфейс приложений. Приложения с собственными рамками (CSD), включая некоторые браузеры, сохраняют свои кнопки. Миниатюры используют разрешённый протокол KDE и KPipeWire только пока открыта панель выбора; при недоступности протокола показываются реальные заголовки и иконки.

## Проверка графики

`ctest` использует изолированные XDG-пути в `build/`. Сохранены старые тесты, добавлены каталог, настройки и панели. На offscreen управление реальными окнами пропускается; его нужно проверять в Wayland.

Native-тест с безопасными тестовыми приложениями:

```bash
XDG_CONFIG_HOME="$PWD/build/test-config" \
XDG_DATA_HOME="$PWD/build/test-data" \
XDG_CACHE_HOME="$PWD/build/test-cache" \
./build/mac-glass-dock --stage4-test --capture "$PWD/build/stage4.png"
```

Добавьте `QT_SCALE_FACTOR=1.5` для дополнительной проверки масштабирования. Native-тест включает протокол окон только временно и выполняет minimize/restore/close исключительно над созданным им тестовым окном. Другие пользовательские окна он не меняет.

В тестовой сборке также доступны `--interaction-test` и снимок собственного окна:

```bash
./build/mac-glass-dock --launcher --capture "$PWD/build/launcher.png"
./build/mac-glass-dock --settings --capture "$PWD/build/settings.png"
cmake --build build --target mac-glass-dock_qmllint
```

Framebuffers не включают результат композиции KWin с рабочим столом. Прозрачные снимки полезны для проверки материала и UI, но не доказывают качество blur на любых обоях. Гарантия 60 FPS на всех GPU не заявляется.

## Безопасность и границы

Обычный запуск не меняет панели или оформление. Действие замены, явно запрошенное пользователем, сохраняет резервную копию и временно перемещает только нижние панели с task manager; оформление применяется отдельно с журналом отката. Добавляется собственное XDG-задание восстановления, которое отключается после возврата. Effect устанавливается только в пользовательский каталог `$HOME/.local/share/mac-glass-dock/refraction`; исходные системные файлы и ресурсы приложений не меняются.

Выбор монитора реализован через Qt/LayerShellQt; физический multi-monitor/hotplug требует отдельной проверки на нескольких экранах. Универсальное скругление сторонних окон, HDR и физически точные отражения остаются исследованием. Во время этапа 4 исходное состояние сохранено в `backups/stage3-source-20261020.tar.gz` без публикации.
