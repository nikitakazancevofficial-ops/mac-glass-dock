Дата: 21 октября 2026. Проект: `/home/nikita/Projects/mac-glass-dock`.

## Изменения интерфейса

- WindowSwitcher появляется после 2000 мс неподвижного наведения. Таймер использует накопленное перемещение относительно центра Dock, а не двигающегося при увеличении делегата; субпиксельное округление не считается движением мыши.
- Возвращена одна деликатная стеклянная поверхность с локальным blurRadius=2.5 DIP, ограниченным преломлением и скруглениями. Удалены внутренняя рамка, общий повторяющийся заголовок/счётчик и повторная подсказка иконки. Остаётся один заголовок каждого окна.
- Источник миниатюры не заменялся: тот же WindowThumbnail, KDE screencast/PipeWire, область 194×102. При отсутствии потока — честное состояние недоступности, не дублирующая иконка.
- Каталог приложений стал менее прозрачным (минимальная плотность материала .58). Открытие и закрытие — обратимая Genie-воронка к реальной кнопке сетки Dock. Нажатие снаружи закрывает панель, не забирая клик у другого приложения; Escape и закрытие по фокусу сохранены.
- Поле поиска принимает первый символ ещё во время открытия; явный мигающий курсор с интервалом 500 мс сбрасывается при вводе. Результаты появляются с конечной анимацией opacity/scale/translate и небольшим stagger, без постоянной перерисовки в покое. Reduced Motion отключает эти движения.
- По уточнению пользователя анимации результатов относятся к каталогу/поиску. Схема добавления и удаления приложений в самом Dock не переделывалась. Числовые параметры любимого пользователем стекла Dock не сбрасывались.

## Почему стекло исчезало в движении и что изменено

Клиентский ShaderEffect может деформировать текстуру собственного интерфейса, но не имеет произвольного доступа к рабочему столу Wayland. До этой доработки отдельный compositor-pass линз не следовал той же сетке, поэтому при полёте оставался только клиентский материал.

Revision `desktop-v8-moving-glass` вводит отдельный `kwin/panelgenie.cpp`: перенаправление собственной launcher surface и деформация её текстуры в KWin. Та же функция `MacGlassGenie::map` деформирует линзы реального фона. Исходные UV отвечают за скруглённую кромку, деформированная позиция — за выборку живого фона. Преломление, chromatic edge и небольшое размытие продолжаются во время перехода. Это не статичный снимок обоев и не обход разрешений Wayland.

Сетка содержимого 48×96, детализация отдельных линз пропорциональна их размеру. Область фоновой копии и damage/scissor следует траектории, а не полному экранному canvas. После окончания снимается redirect. Исправлены чтения QJsonObject через operator[], случайно вставлявшие пустые записи окон: теперь `.value()`, в тестах после выхода клиента pid=0/windows=0.

Отдельный handshake предотвращает вспышку исходного прямоугольника при первом map: подтверждение KWin содержит текущий surface ID, до него содержимое прозрачно. Таймаут 700 мс выбирает клиентский fallback, поздний ответ не меняет путь посреди анимации. CPU input mask и проверка внешнего клика используют тот же округлый деформированный контур. Прозрачная часть travel-canvas пропускает ввод.

Старая математика анимации обычных приложений, защита от конкурирующего Squash и конечной вспышки сохранены; добавлена только отдельная диспетчеризация собственной панели. Системный Squash не отключается. Общие эффекты/настройки KWin не переписываются.

## Запуск после перезагрузки

По явному запросу пользователя реализован включаемый автозапуск в пользовательском XDG-каталоге:

- `~/.config/autostart/org.macglass.Dock.desktop` вызывает независимый `~/.local/state/mac-glass-dock/recover.py login`.
- Сохраняется абсолютный путь текущего проекта. Helper ждёт KWin/Plasma, проверяет существующий Dock, запускает `scripts/session.sh` (установленный модуль, затем клиент) и проверяет готовность Wayland surface. flock защищает от двух параллельных helper.
- При ранее активной интеграции сохраняется левая панель Plasma со всеми её виджетами и исходной резервной копией. Если интеграция не была включена, автозапуск сам панель не перемещает.
- Старое задание Recovery отключается; даже уже поставленный в очередь restore-login проверяет persistent-флаг и не конкурирует с Dock.
- При пропавшем проекте/сборке или неудачном запуске выполняется попытка вернуть исходную панель и отключить собственный автозапуск. Завершается только созданный helper дочерний процесс. Это не универсальный watchdog последующих сбоев KDE.
- В настройках есть отдельная кнопка включения/отключения автозапуска. Полный возврат панели также отключает его. Резервная копия не удаляется.

Сборка и установка сами по себе автозапуск не включают. Проверка реальной перезагрузкой компьютера агентом не выполняется.

## Ограничения

Настоящее движущееся преломление требует совместимого собственного OpenGL-модуля KWin. Клиентский `.qsb` fallback деформирует интерфейс, но не рабочий стол во время полёта; software backend использует scale/fade. Модуль привязан к установленному SDK KWin и после его обновления может потребовать пересборки. Мультимониторный mixed-DPR, HDR и произвольные сторонние эффекты отдельно не сертифицированы. Пиксельная/временная идентичность macOS по неподвижным референсам не заявляется.

## Команды

```bash
./scripts/build.sh
ctest --test-dir build --output-on-failure
./scripts/session.sh
./build/mac-glass-dock --settings
python3 scripts/desktop-session.py status
python3 scripts/desktop-session.py enable-autostart
python3 scripts/desktop-session.py disable-autostart
./scripts/session.sh --restore-plasma
```

Последняя команда возвращает исходную панель/оформление, отключает автозапуск и завершает Dock. Отключение только автозапуска не закрывает текущий Dock. Не удаляйте/перемещайте checkout и build при включённом автозапуске; после переноса включите его заново из нового пути.
