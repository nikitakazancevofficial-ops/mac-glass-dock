# Оптический материал этапа 4

Главный визуальный референс — третье изображение пользователя: прозрачный центр, толстая округлая кромка, локальный свет и фон, просвечивающий через поверхность. Общий компонент — VolumetricGlassSurface.qml; старый GlassSurface служит адаптером.

## Слои

- **Background integration:** KWindowEffects запрашивает blur в скруглённом регионе окна. На проверенном KWin используется ext_background_effect_manager_v1; фон клиенту не передаётся. При отсутствии/отключении blur тело становится немного плотнее, но не заменяется картинкой обоев.
- **Glass body:** нейтральная слабая тонировка, настраиваемая плотность. Crystal Clear использует 0.04. Автотема следует системному color scheme; клиент не считывает пиксели обоев.
- **Thickness profile:** расстояние до SDF-кромки формирует профиль bevel и нормаль. Геометрия и радиус влияют на освещение углов.
- **Edge optics:** тонкий направленный световой контур, Fresnel-like коэффициент, внутренняя тень и очень слабый цветовой сдвиг на границе. Яркое внутреннее кольцо убрано, а малые кнопки используют более узкую фаску opticScale. Это художественная оптическая модель, не физическая дисперсия рабочего стола.
- **Specular:** зависимость от нормали и указателя, ограниченные по интенсивности блики. Центральный блик ослаблен, чтобы не создавать мутную белую заливку.
- **Depth:** мягкая аналитическая внешняя тень и внутренняя тень по нормали. Размеры собственных окон включают поля для рисунка теней.

Зернистость предыдущего шейдера удалена. Постоянного time uniform и бесконечного material animation нет. Рендер инициируют ввод, анимации, изменения параметров/геометрии и job-индикатор.

## Pipeline

GLSL 440 компилируется Qt ShaderTools в QSB с вариантами SPIR-V/GLSL/HLSL/MSL. Материал использует один fragment pass, premultiplied alpha и SDF anti-aliasing. Дополнительные полноэкранные framebuffer copies не создаются. Вложенные карточки/кнопки добавляют небольшие draw calls внутри общей области системного blur.

Adaptive Rounded использует shader выбора оригинальной текстуры внутри padded square. Кромка и подложка принадлежат только общему материалу, без второй superellipse-плашки поверх линзы. Hover меняет свет внутри той же поверхности. Иконки используют mipmap при уменьшении; SDF anti-aliasing следует физическому пикселю. Ни один режим не меняет файлы иконок.

Soft Glass, отключённый GPU и software backend используют QML fallback с многозонным градиентом и двумя кромками. Возможна разница качества скруглений/теней относительно GPU; это fallback, а не обещание полного совпадения.

## Что является настоящим, а что ограничено

Настоящие: прозрачное окно, GPU-расчёт материала, реальные нормали/свет SDF-геометрии, QSB, системный blur при capability композитора, геометрические input regions.

Пользовательский KWin Effect теперь реализует рефракцию фоновых пикселей под собственными поверхностями и отдельными иконками. Его регуляторы активны при доступном backend. Обновление фона проходит через scene damage tracking KWin. Отражение реального окружения, оценка яркости обоев и полная физическая точность macOS остаются дальнейшей работой.

Фон позади Wayland-окна не является текстурой обычного ShaderEffect. Для полной рефракции нужен отдельный разрешённый compositor-side путь с учётом стека окон, damage, DPR, HDR и обратной связи с приложением. Концепция и реальные API описаны в [KWIN_STAGE4_RESEARCH.md](KWIN_STAGE4_RESEARCH.md). Screen capture обходы не используются.

## Проверка качества

Сравнивать следует силуэт, толщину/свет кромки, прозрачность центра, читаемость, поведение при hover и согласованность всех панелей. Framebuffer-снимок собственного окна показывает материал с alpha, но не включает blur и итоговую композицию KWin с обоями. Скриншот нельзя считать доказательством полного desktop refraction.

GPU-совместимость, кадровые интервалы и отсутствие idle repaint проверяются отдельно. Стабильные 60 FPS на всех GPU, HDR и длительное отсутствие утечек требуют расширенного профилирования.

## API

[Qt ShaderEffect](https://doc.qt.io/qt-6/qml-qtquick-shadereffect.html), [KWindowEffects](https://api.kde.org/kwindoweffects.html), [KWin Effects](https://api.kde.org/kwin-effects.html). Реализация дополнительно сверялась с установленными версиями заголовков и фактическими Wayland capabilities.
