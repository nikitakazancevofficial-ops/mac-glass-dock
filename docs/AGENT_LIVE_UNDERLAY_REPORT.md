# Живой фон при сворачивании каталога

21 октября 2026. Уточнённый сценарий пользователя: закрытие каталога «Приложения» с поиском, когда за его верхней частью находится небольшое окно. Обычная анимация приложений и внешний вид Dock не являются целью изменений.

## Найденная ошибка

В `kwin/lens.frag` движущаяся линза уже получала текущие экранные координаты samplePosition, но добавка zoom всё ещё вычислялась через `local` — координаты исходного, ещё не свёрнутого полотна. При zoom=1 добавка нулевая, поэтому прежний тестовый режим выглядел правильно. При пользовательском CenterZoom=0.94 выборка фона зависела от движущихся исходных UV: детали за стеклом визуально увлекались за полотном. Это координатная ошибка, а не намеренная замена рабочего стола статичным снимком.

Теперь и zoom, и основная выборка фона рассчитываются в экранном пространстве относительно текущего деформированного центра каждой линзы. Исходные UV используются только для формы/кромки материала. Центр передаётся из C++ через lensCenter в координатах текущего cropped backdrop. Неанимированная ветка shader, включая Dock, оставлена без изменений. Полотно интерфейса продолжает деформироваться прежней Genie-сеткой, фон выбирается отдельно из текущего render target композитора.

Проверена также гипотеза попадания линз в посторонние offscreen targets: временная QA-инструментация показала 0 таких проходов в воспроизведении. Эта диагностическая инструментация удалена, ненужные изменения цепочки paintScreen в исправление не включены.

## Проверки регрессии

Новый GPU-тест `movingGlassDoesNotCarrySourceBackground` фиксирует геометрию назначения, меняет исходные UV и использует zoom=.94. В прозрачном центре фон не должен зависеть от исходных UV. На старой формуле различались 27069 пикселей проверяемой области; на новой — 0. Дополнительно подаётся изменённое изображение фона: выход должен измениться, то есть проверяется не замороженный результат. Исходные тесты кромки, размытия и отдельной icon lens сохранены.

Native-тест каталога также использует .94, а QA-сценарий запускает маленькое настоящее окно с обновляющимся содержимым за верхней частью панели. Числовые пользовательские настройки не перезаписываются.

## Память и сборка

После сообщения пользователя о нехватке RAM сборки выполняются последовательно, `--parallel 1`, без одновременного запуска компиляторов разных build-каталогов. В scripts/build.sh и scripts/refraction.sh консервативное значение по умолчанию изменено с 2 на 1. Повысить его явно можно через CMAKE_BUILD_PARALLEL_LEVEL. Swap, системные лимиты, процессы других приложений и настройки Linux не менялись. Причина системных завершений процессов не установлена; они не объявляются доказанной утечкой Dock.
