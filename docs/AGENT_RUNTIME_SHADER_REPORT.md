# Изоляция версий эффекта в работающем KWin

21 октября 2026.

Повторные repaint-запросы не устранили сообщённый пользователем перенос
старого фона вместе с Genie-панелью. Они удалены из исправления.

При горячей перезагрузке Qt сохраняет загруженные библиотеки. Ранее все
версии экспортировали одинаковые имена методов MacGlassRefraction,
qInitResources_shaders и ресурсы :/macglass/lens.frag. Поэтому уникальный
путь файла .so сам по себе не изолировал исполняемый код и шейдеры версий.

В текущем сеансе после изменения расположения полей класса возникло
показательное расхождение: warpedLenses=10374 при panelMotionFrames=0
и panelBackgroundRepaints=0. После локальной привязки функций через
-Bsymbolic-functions и изоляции ресурсов новый модуль показал
panelMotionFrames=27, panelBackgroundRepaints=49, warpedLenses=793.
Это подтверждение исправления согласованности runtime, а не само по себе
доказательство визуального качества стекла.

CMake вычисляет SHA256 содержимого трёх шейдеров. Этот хеш входит как
в prefix Qt-ресурсов, так и в имя генерируемого qrc, чтобы различались
также символы его инициализации. В diagnostics добавлен shaderPrefix.
Revision: desktop-v11-isolated-shaders.

Дополнительно копирование backdrop временно отключает GL_SCISSOR_TEST:
экранная область отсечения не должна применяться к cropped FBO с началом
координат (0,0). Состояние восстанавливается после каждой копии. Счётчик
scissoredCaptures в первом живом прогоне был равен 0, поэтому эта защита
не объявляется подтверждённой причиной конкретного пользовательского случая.

Гипотеза повторного входа в этот же эффект при OffscreenEffect::maybeRender
проверена и отвергнута: диагностический счётчик был 0. Временный guard удалён.
EffectsHandler продолжает цепочку со следующего эффекта.

Параметры материала, анимация и защита от повторного появления закрытой
панели сохранены. Визуальное подтверждение результата в пользовательском
сеансе запрошено отдельно; автоматические счётчики его не заменяют.

Пользователь подтвердил на установленном модуле в текущем сеансе:
«теперь фон реально работает так как надо». Production release:
f4a96afea837c43c8034. Тесты optics_shader_test и genie_geometry_test прошли.
Проверка дизассемблированного production-модуля подтвердила прямые локальные
вызовы syncPanelMotions/applyPanelMotion вместо PLT; символ инициализации
ресурсов содержит хеш шейдеров.
