# Обновление оптики, работающих приложений и окон

Дата: 21 октября 2026 года. CachyOS, Qt 6.12.0, KWin 6.8.0, AMD Radeon Vega 8.

## Исправления

1. Публикация геометрии больше не использует перезапускаемый debounce 16 мс. Изменения объединяются за оборот event loop и не отодвигаются следующими событиями анимации.
2. Фоновые зависимости объявлены через `BackgroundEffectItem`, как требует scene damage tracking KWin 6.8. Текстуры раздельны по RenderView и имеют физическое разрешение viewport.
3. Сглаживание SDF следует производным физических пикселей. Уменьшенные иконки используют mipmap.
4. Убраны отдельная прямоугольная hover-плашка и вторая подложка Adaptive Rounded. Блик указателя изменяет общий материал иконки.
5. Линзы прокручиваемых делегатов имеют отдельный clip rect. Геометрия исходного скругления сохраняется при частичном обрезании; скрытые делегаты не создают фантомных линз.
6. Состав ApplicationModel обновляется через insert/remove/move без сброса всего ряда. Running-only группы стабильно сортируются. Начальные skip-taskbar окна остаются подписаны на изменение состояния.
7. Добавлен отдельный WindowAnimations. Нормальные управляемые окна временно направляются в текстуру для scale/fade/blur. Эффект использует TimeLine, grab roles и visible/deleted refs; при завершении, отмене, закрытии во время открытия и выгрузке ресурсы освобождаются.
8. Escape обрабатывается полем поиска и рамкой собственных панелей. Проверка прозрачности использует координаты с учётом DPR.
9. Добавлен scripts/refraction.sh для сборки, установки по хешу и session-only загрузки. QA-модуль не устанавливается, загруженные библиотеки не перезаписываются.

## Проверки

Сборка клиента и production-модуля успешна. CTest: 6/6, QML lint: успешно. Native UI: 10/10 при 100% и реальных 150%; session tests: 6/6 в обоих режимах. Отдельный прогон пользовательского установщика в чистом вложенном сеансе с двумя последовательными `enable` также прошёл 6/6 плюс 10/10 native UI. Логи: `build/refresh-ctest-final.log`, `build/refresh-lint.log`, `build/refresh-hidpi-final2.log`, `build/refresh-production-test.log`, `build/refresh-loader-test.log`.

QA-проверка читает реальные пиксели только из вложенного тестового композитора с собственным движущимся узором. Она зафиксировала 32 изменения фона Dock за 1005 мс при масштабе 100%, в заключительном прогоне 25 за 1004 мс при viewport scale 1.5 и ноль дополнительных lens draws после остановки фона. Это проверка обновления, а не production FPS benchmark: QA делает дорогой GPU readback, отсутствующий в production.

Реальный HiDPI подтверждён диагностикой FBO: Dock 833×279 физических px, settings 738×795, scale 1.5. Вложенный Wayland backend KWin по умолчанию следует масштабу родителя, поэтому простого `--scale` оказалось недостаточно. Только QA-сборка настраивает собственный синтетический WL-* выход и проверяет DPR окна. Масштаб рабочего стола пользователя не меняется.

Проверены два открытия и два закрытия, в том числе закрытие во время появления; `activeMotions=0` после завершения. Проверены реальные состояния собственного probe-окна: появление, минимизация, восстановление, закрытие и отсутствие modelReset. Проверка `liveOpticalGeometry` требует обновления состояния во время увеличения иконки, а не только после окончания анимации.

QA-кадры находятся в `build/refresh-hidpi-final2-*.png`, `build/refresh-final-composed-*.png`. Кадры корректируют ориентацию OpenGL readback перед сохранением. Production не содержит пиксельного readback и не экспортирует capture endpoint.

В текущем сеансе загружена revision `refresh-v2`, `motionShader=true`, `windowAnimations=true`, клиент PID 61615. После включения интеграции в Dock появились дополнительные реальные работающие приложения; диагностически зафиксировано 11 icon lenses, включая две управляющие кнопки. Количество меняется при открытии/закрытии окон.

При обновлении обнаружено ограничение защищённых QML-модулей Qt: повторная регистрация MacGlassBootstrap из нового каталога запрещена. Загрузчик теперь держит wrapper по каноническому пути `refraction/native`, а versioned entry point импортирует уже зарегистрированный URI. Проверены холодная регистрация и повторная загрузка. Перезапуск KWin не требовался.

Контрольные хеши на начало и конец этого обновления совпали: `kwinrc` — `5d3e4b2156692417827f3af3d0b30830f71b2b86e788ead39ceec55f8c31ee44`, Plasma appletsrc — `6db81d1636597cee2df458399c143fc6be7daa1e75dca89d30649b5a84f35226`. Ранее сохранённые пользовательские параметры: `backups/user-settings-before-running-20261021.ini`; изменены только WindowIntegration и WindowAnimations в собственной конфигурации Dock.

## Эксплуатация

```bash
./scripts/build.sh
ctest --test-dir build --output-on-failure
./scripts/refraction.sh build
./scripts/refraction.sh install
./scripts/refraction.sh enable
./build/mac-glass-dock --settings
```

`./scripts/refraction.sh disable` возвращает обычный blur; `--preview` работает без композиторной рефракции. Загрузка эффекта выполняется только в текущем сеансе, автозапуска нет. Пользовательские параметры материала и закрепления сохраняются. В текущем профиле включаются только собственные опции WindowIntegration и WindowAnimations.

## Ограничения и дальнейшая работа

Анимация scale/fade/blur не является точной копией macOS или Genie/Magic Lamp. Долговременные 60 FPS, HDR, физический multi-monitor/hotplug и взаимодействие со всеми сторонними эффектами не сертифицированы. Захваченные другим эффектом transition roles, fullscreen, специальные, popup и lock-screen окна исключаются. Преломление по-прежнему ограничено собственными поверхностями Dock.

Полная физическая идентичность Liquid Glass и отсутствие любых возможных ошибок не заявляются. Профилирование production GPU, дополнительные формы света и проверка разных приложений остаются следующим направлением развития.

Основные API сверялись с установленным SDK и исходниками KDE: [BackgroundEffectItem](https://github.com/KDE/kwin/blob/Plasma/6.8/src/scene/backgroundeffectitem.cpp), [OffscreenEffect](https://github.com/KDE/kwin/blob/Plasma/6.8/src/effect/offscreeneffect.cpp).
