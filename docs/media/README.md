# Media provenance

- `desktop.webp`, `control-center.webp`, `launcher.webp`: screenshots supplied by the author on 2026-10-23. WebP encoding for README delivery; no generated UI or replaced desktop content.
- `banner.svg`: original vector project banner, decorative artwork rather than an application screenshot.

Screenshots depict third-party application marks and a desktop wallpaper. These remain their respective owners' property. No separate wallpaper or third-party icon pack is distributed. See [notices](../../THIRD_PARTY_NOTICES.md).

- `tahoe-desktop.webp`, `tahoe-launcher.webp`, `tahoe-control-center.jpg`: real captures of the app in an isolated 1920×1080 virtual KWin 6.8.0 compositor, with a sample catalogue and the Apple Tahoe Beach Day image as the backdrop. UI and refraction are rendered by the project itself.
- `genie-demo.gif`: 58 sequential compositor frames from the same session; 960×540, approximately 9 frames/s for delivery, animation setting 0.45. Not a benchmark and not a wallpaper animation. JPEG capture encoding was used only in a private QA build to reduce screenshot I/O stalls; production rendering/shaders were unchanged.

No standalone copy is bundled or automatically installed. The project license does not cover the depicted Apple artwork.
